## 1. v1 study (read at `archive/v1-final`)

**How v1 did it:**
- `public/index.html` + 44 classic scripts in `public/scripts/`, all sharing `window.*` (`window.ws`,
  `window.chatInput`, `window.allMemories` …). No modules, no types.
- `public/scripts/chat.js` → `connect()`: `new WebSocket`, `onclose` → fixed `setTimeout(connect, 3000)`,
  `onmessage` → `JSON.parse` → `handleMessage` (no check). `onopen` sends `init` or `set_lang` again.
- `public/index.js` (298) → DOM wiring, `localStorage`, `innerHTML` with string-built markup.

**Best parts (keep):** reconnect on close with a banner, no timers left behind (`chat.js:38`) · the socket
drops on every server restart, so "offline" is a normal state, not an error.

**Bad parts (drop / fix):**
- Globals everywhere: any file could touch the socket or the DOM (the plan's Phase 3 rules forbid both).
- AP8 on the client: inbound frames are never checked.
- Fixed 3 s retry, no backoff · `innerHTML` with data (XSS risk) · inline `onclick`s (L-C11).

**Lessons:** L-P01 (preview before visuals) · L-C11 (CSP, no inline) · AP6 (bounded) · AP7 · AP8.

## 2. Spec (the contract)

**Goal:** an empty page that loads as plain files, connects, shows the link state, and is type-checked.

**Behaviour:**
1. `public/index.html`: one `<aperio-app>` + one `<script type="module" src="main.js">`. No inline code.
2. `public/state/store.js` (~50 lines): `createStore(initial)` on `EventTarget`.
   `get(key)` · `set(key, value)` (notifies only when the value changed, `Object.is`) ·
   `subscribe(key, fn) → unsubscribe` · `subscriberCount()` (for the leak test).
3. `public/services/socket-service.js`: `createSocketService({ store, url, WebSocket })`. Connects;
   sets `connection` = `connecting | open | closed`. On close it reconnects with backoff
   (0.5 s → ×2 → max 10 s, reset on open). Inbound: `parseServerFrame` (new, §4.1); a bad frame →
   `console.warn` + `store.set('lastError', …)`, never thrown. Outbound: `send(msg)` checks with
   `encodeClientFrame` (new); returns `false` when closed. `dispose()` stops timers and the socket.
   The service never touches the DOM. The store keeps its state across reconnects.
4. `public/components/app-shell.js`: `<aperio-app>` shows the `connection` word. Subscribes in
   `connectedCallback`, unsubscribes in `disconnectedCallback`. Uses `textContent`, never `innerHTML`.
   It never imports the socket; it gets the store only.
5. `public/main.js`: makes the store + service, defines the element. The only file that wires them.
6. Every file: `// @ts-check` + JSDoc. `tsconfig.json`: `checkJs`, `noEmit`, `strict`, `lib: dom`,
   includes `public/**` + `src/shared/ws-schema.js`. `npm run typecheck` → in `npm run check` and CI.
7. ESLint gets a `public/**` block with browser globals; AP5/AP6/AP8 apply there too.

**Errors:** server down → `closed`, then retries (no error shown) · bad server frame → warn + `lastError`
· `send` while closed → `false` (the caller decides).

**Limits:** backoff max 10 s · one socket per page · store keys are fixed names (no unbounded map).

**Non-goals:** styles, tokens, layout (S3.1/S3.2) · chat (S3.3) · Playwright (T3.x) · i18n · `localStorage`.

**Keeps / drops:** keeps reconnect-on-close · drops globals, fixed 3 s retry, unchecked `JSON.parse`, `innerHTML`.

## 3. Acceptance (becomes T3.0)

- [ ] store: `set` notifies subscribers of that key once; same value → no notify; unsubscribe works
- [ ] leak: the component attached then removed → `subscriberCount()` is 0 (tiny `HTMLElement` stub, no jsdom)
- [ ] socket: fake `WebSocket` drops → service reconnects with backoff; the store keeps its other keys
- [ ] socket: a bad server frame is dropped with a warning; a good one reaches the store
- [ ] `dispose()` leaves no timer (`node --test` exits)
- [ ] shell loads with no build: S2.14 server + fake provider on a free port; `/`, `/main.js` and every
      module it imports → 200; a Node `WebSocket` client connects
- [ ] `tsc --noEmit` green; a planted JSDoc type error (temp copy) → `tsc` exits non-zero
- [ ] `package.json`: no framework or bundler (react, vue, angular, lit, svelte, preact, solid, vite, webpack, esbuild, rollup, parcel)
- [ ] no inline `<script>`, `<style>`, `style=` or `on*=` in `public/` (ported from v1 CSP test)
- [ ] by hand, once: the page in Chrome says `open`; stop the server → `closed`; start it → `open`
