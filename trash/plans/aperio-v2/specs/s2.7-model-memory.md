# Spec S2.7 (rev 3) — The model decides: memory through tools only

Status: **approved 2026-11-11** — developer decision: the model has autonomy. It decides when to
save and when to search. Code no longer captures or injects. Replaces `s2.7-auto-capture.md`.
Plan step: `aperio-v2.md` → S2.7 · Tests: T2.7 (rewritten).

## 1. What changes and why

**Decision (developer, 2026-11-11):** "Let the model decide. This is why we have the agent — so the
model can work and have autonomy." Option 2 of 2, chosen over "code + tools both".

**Known risk, written down (not a blocker):** v1 lesson L-M02 — QWEN3 did not call `recall`
reliably and treated a 5-row preload as everything. The eval below measures it on gemma, so we
see the real number instead of guessing.

## 2. Spec

1. **Code capture (S2.7 rev 2) is dropped.** `src/capture/` is not committed. Its red tests
   (commit `4e9f3975`) are removed, apart from `secret-scan` (moves to the `remember` tool).
2. **Code auto-recall (S2.6) leaves the turn path.** `buildRecallBlock` is no longer called per
   turn; the user turn is the user's text. `src/context/recall-block.js` and its tests are deleted;
   `RECALL_*` keys are removed except `RECALL_TOP_K` (the tool's default limit).
3. **S2.8 moves up and becomes this step:** the model gets `remember` and `recall` tools
   (in-process, `run(args, ctx)`). `update`, `forget`, `list` stay in S2.8.
   - `remember({ content, title?, type? })` → saves with vector + signature; secret check
     (`hasSecret`) refuses; duplicate check (cosine ≥ 80, measured in rev 2) returns the old id.
   - `recall({ query, limit? })` → semantic + full-text search, returns title + content + date.
4. **System prompt** (≤ 1.5k tokens) gets 2 lines: when the user asks you to remember, call
   `remember`; when a question may need something said before, call `recall` first.
5. **Stable prefix holds:** the tool array is fixed from turn 1 (both tools always present).
