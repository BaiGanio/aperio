# <span class="kicker">Part 1</span> Create a file {#create}

<p class="promise">After this page, you can ask Aperio to build a spreadsheet or document for you, right in chat, and save it to your computer.</p>

Say you want a shopping list, a simple budget tracker, or a set of scribbled notes typed up properly. Just describe it in plain words — Aperio builds a real file, not a wall of text in the chat. A few real examples:

<ul>
<li><em>"Make me a spreadsheet with columns for date, item, and cost — I want to track my grocery spending."</em></li>
<li><em>"Turn this list into a packing checklist I can print."</em></li>
<li><em>"Write these notes up as a document I can send to my team."</em></li>
</ul>

<ol class="steps">
<li>In chat, describe the file you want, in plain words.</li>
<li>Watch the small card that appears in the chat — it fills in while Aperio builds the file.</li>
<li>When it's done, open the card to preview it, or click <strong>Download</strong> to save it to your computer.</li>
</ol>

<div class="done-check"><span class="label">Done looks like</span>A finished file card appears in the chat, and Download saves a real spreadsheet or document to your computer.</div>

<blockquote class="snag"><p><strong>The file isn't quite what I wanted.</strong> Ask again with more detail — the exact column names, or the exact wording — the same way you'd correct a person.</p></blockquote>
<blockquote class="snag"><p><strong>I don't see a Download button yet.</strong> Large files take a moment to build. Wait for the spinner on the card to finish.</p></blockquote>

# <span class="kicker">Part 2</span> Give Aperio a file to read {#read}

<p class="promise">After this page, Aperio can read a file you already have and answer questions about it — no retyping.</p>

Say you have a PDF bill, a Word document, a budget spreadsheet, or a photo of a handwritten receipt. Attach it, then ask about it in plain language. Aperio reads what's actually in the file instead of guessing — typed or scanned, it doesn't matter:

<ul>
<li><em>"What's the total on this bill?"</em> — a PDF</li>
<li><em>"Summarize this report in three sentences."</em> — a Word document</li>
<li><em>"What did we spend on the Expenses tab in June?"</em> — a spreadsheet</li>
<li><em>"What does this say?"</em> — a photo of a handwritten note or a receipt</li>
</ul>

<ol class="steps">
<li>Next to the chat box, click the paperclip icon (<strong>Attach files</strong>), or drag the file in.</li>
<li>Ask your question about it in plain language.</li>
<li>Read Aperio's answer — it comes from what's actually in the file.</li>
</ol>

<div class="done-check"><span class="label">Done looks like</span>Aperio's answer matches something really in the file you attached.</div>

<blockquote class="snag"><p><strong>Aperio says it can't read the file.</strong> It reads PDFs, Word documents, spreadsheets, PowerPoint slides, plain text, and images (including photos of paper documents). For anything else, save or export it to one of those first.</p></blockquote>
<blockquote class="snag"><p><strong>The file is long, and the answer misses something.</strong> Ask about one part at a time — for example, <em>"What's on page 3?"</em> or <em>"Just the Marketing section, not the whole report."</em></p></blockquote>

# <span class="kicker">Part 3</span> Search a whole folder at once {#search}

<p class="promise">After this page, Aperio can search and answer questions across every file in a folder you choose — not just one file at a time.</p>

Say you have a folder of household papers — insurance policies, warranties, instruction manuals, spreadsheets, even a few scanned pages. Instead of attaching them one at a time, point Aperio at the whole folder once. It reads everything inside and remembers which file each answer came from, so it can also trace one detail across many files at once:

<ul>
<li><em>"Index the documents in my Household Papers folder."</em></li>
<li><em>"Which of my policies covers water damage?"</em></li>
<li><em>"Which documents mention policy number HO-88214?"</em> — finds it everywhere it appears, even across different files</li>
<li><em>"Just show me the coverage section of the home insurance policy, not the whole thing."</em></li>
</ul>

<ol class="steps">
<li>In chat, tell Aperio the folder and ask it to index it.</li>
<li>Watch progress in the <strong>Docs</strong> panel, in the sidebar — indexing runs in the background, so you can keep chatting.</li>
<li>Once it says done, ask your question naturally. Aperio searches the whole folder for you.</li>
</ol>

<div class="done-check"><span class="label">Done looks like</span>Aperio answers using the right file from the folder, and can tell you which one it came from.</div>

<blockquote class="snag"><p><strong>Aperio says it isn't allowed to read that folder.</strong> Open <strong>Settings → Allowed folders</strong> and add it — Aperio only reads folders it's been given permission for.</p></blockquote>

<div class="note-box"><span class="label">Worth knowing</span><ul>
<li>If the folder is a programming project instead of documents, Aperio can also map how the code fits together — look for <strong>Code</strong> in the sidebar. (Not shown on Aperio-lite, since it's built for developers.)</li>
<li>Indexing only reads folders already on this computer — Aperio never uploads your files anywhere.</li>
</ul></div>

You've now asked Aperio to build files, read the ones you already have, and search a whole folder at once — all using files already on your own computer.
