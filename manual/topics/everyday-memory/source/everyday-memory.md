# <span class="kicker">Part 1</span> Find a memory {#search}

<p class="promise">After this page, you can find any memory Aperio has saved by typing a few words — no scrolling through a long list.</p>

Say you told Aperio your Wi-Fi password months ago and can't picture where. Open the Memories panel and type "Wi-Fi." Aperio finds it — even without the exact words you used originally, because it searches by meaning as well as by exact words. The same works for almost anything you've told it before:

<ul>
<li>"Wi-Fi password" finds it, even if you originally said "the network key for the house."</li>
<li>"vet phone number" finds it, even if you saved it as "Dr. Alvarez, animal clinic."</li>
<li>"car license plate" finds it, even months after you mentioned it once, in passing.</li>
</ul>

<ol class="steps">
<li>In Aperio's sidebar, open <strong>Memories</strong>.</li>
<li>Type a few words about what you're looking for into the search box.</li>
<li>Read the results — the closest matches appear first.</li>
</ol>

<div class="done-check"><span class="label">Done looks like</span>The memory you were thinking of is somewhere in the results, usually near the top.</div>

<blockquote class="snag"><p><strong>Nothing comes up.</strong> Try fewer, plainer words. Aperio matches meaning, not just exact spelling, but a very short or unusual search can still miss.</p></blockquote>
<blockquote class="snag"><p><strong>Too many results, and not the one I want.</strong> Add one more specific word — a name, a place, a date — to narrow it down.</p></blockquote>

# <span class="kicker">Part 2</span> Fix a memory {#fix}

<p class="promise">After this page, you can correct a memory that's outdated or wrong — without deleting it and starting over.</p>

Aperio remembers your coffee order as "oat milk flat white" — but you've switched to almond milk. Just tell Aperio, in chat, that it's wrong. There's no separate edit screen: correcting a memory is a conversation, the same way you'd correct a person. A few real examples:

<ul>
<li><em>"My coffee order is almond milk now, not oat milk."</em></li>
<li><em>"Update my address — I moved to 12 Oak Street last month."</em></li>
<li><em>"The vet's number changed. Here's the new one: 555-0142."</em></li>
</ul>

<ol class="steps">
<li>Start a chat with Aperio.</li>
<li>Say what's outdated and what it should be instead, in one plain sentence.</li>
<li>Wait for Aperio to confirm it updated the memory.</li>
</ol>

<div class="done-check"><span class="label">Done looks like</span>Aperio confirms the change, and searching for that memory now shows the new information.</div>

<blockquote class="snag"><p><strong>Aperio saved a second, separate memory instead of correcting the first one.</strong> Be explicit that you're correcting something it already knows, not telling it something new — for example, say "update what you remember about my coffee order," not just "my coffee order is almond milk."</p></blockquote>

# <span class="kicker">Part 3</span> Tidy the list {#tidy}

<p class="promise">After this page, your most useful memories stay easy to find, and the ones you don't want are gone for good.</p>

The longer you use Aperio, the longer its memory list gets. Two tools keep it useful: pin the memories you check often, so they stay at the top; delete the ones you don't want remembered at all. For example, pin your emergency contacts or your medication schedule; delete the memory of a job you left, a subscription you cancelled, or a note that's just wrong.

<ol class="steps">
<li>In the Memories panel, find the memory you want to change.</li>
<li>To keep it at the top of the list, click its pin icon — it moves into a <strong>Pinned</strong> group.</li>
<li>To remove it completely, click its trash icon and confirm the delete. Or just tell Aperio in chat: <em>"Forget the note about my old apartment — I don't live there anymore."</em></li>
</ol>

<div class="done-check"><span class="label">Done looks like</span>Pinned memories stay grouped at the top of the list; deleted memories no longer appear in search or in chat.</div>

<blockquote class="snag"><p><strong>I deleted the wrong memory.</strong> Deleting is permanent — there's no undo. If you're not sure, search for the memory first and read it in full before deleting.</p></blockquote>

<div class="note-box"><span class="label">Worth knowing</span><ul>
<li>Memories carry tags. Click a tag in the list to see only memories with that tag; click the clear button to remove the filter.</li>
<li>Sometimes Aperio notices something worth remembering on its own during a chat, and asks first instead of saving it right away — that shows up as a waiting item in the Memories panel for you to approve or reject.</li>
</ul></div>

You've now searched, corrected, and tidied your own memories — everything here happened inside Aperio's own chat and Memories panel. Want that same memory available inside Claude, Codex, or another AI tool you already use? That's covered in the *Connecting Aperio to your world* topic.
