# Aperio

**One brain. Nothing forgotten.**

A self-hosted personal memory layer for a local AI model. Node.js, SQLite, llama.cpp.
MIT licensed.

> *"All inquiry and all learning is but recollection."* — Plato, **Meno** 81d

## Status: being rebuilt

Aperio v1 grew past what one person can maintain, and past what a small local model can use
well. It is being rebuilt as a **small core**, on this branch, guided by one rule:

> **On a small model, code does the memory work. The model does the talking.**
> Recall is woven into the turn by code, not a tool the model has to remember to call.

- **The plan:** [`trash/plans/aperio-v2/aperio-v2.md`](trash/plans/aperio-v2/aperio-v2.md)
- **What happens to every v1 feature:** [`feature-ledger.md`](trash/plans/aperio-v2/feature-ledger.md)
- **What v1 taught us:** [`lessons-ledger.md`](trash/plans/aperio-v2/lessons-ledger.md)
- **All of v1, forever:** tag `archive/v1-final` — `git show archive/v1-final:FEATURES.md`
- **v1 changelog:** [`docs/changelog-v1.md`](docs/changelog-v1.md)

The first release of the new core will be **v1.0.0**. Until then, nothing here installs.
The v1 release remains on the `release` branch.
